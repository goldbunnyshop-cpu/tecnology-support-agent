                         🎯 FIX #2: COMANDO NOSHOW

 PROBLEMA:
   Grupo recibe: ✓ "✅ Follow-up enviado a Juan... Cupón: ABC123XY..."
   Cliente recibe: ✗ "Hola, parece que tu mensaje tiene un formato..."

   Causa: generar_respuesta() llamada incorrectamente
          - prompt_contexto pasado como "mensaje del cliente"
          - Faltan parámetros: telefono, nombre_cliente
          - Claude recibe instrucciones como mensaje confuso

   Impacto: Cliente confundido, oportunidad de reconexión perdida

 SOLUCIÓN:
   Archivos: agent/brain.py (nueva función 278-345) + agent/commands.py (857-876)

   ✓ Nueva función: async def generar_mensaje_noshow()
     - Recibe: telefono, nombre_cliente, historial, cupon, fecha_expira
     - Inyecta contexto empático en system_prompt
     - Mensaje trigger claro para Claude
     - Fallback empático si falla Claude

   ✓ Actualizar commands.py
     - Reemplazar generar_respuesta() con generar_mensaje_noshow()
     - Pasar parámetros correctamente estructurados

 RESULTADO:
   Cliente recibe: "Hola Juan, notamos que no pudiste asistir...
                   Cupón: ABC123XY (10% descuento)..."

   Grupo recibe: "✅ Follow-up de no-show enviado a Juan..."

   → CONSISTENCIA ✓ + EMPATÍA ✓ + RECONEXIÓN ✓

 IMPACTO:
   Antes:  Confusión → Pérdida de cliente
   Después: Empatía → Oportunidad de reconexión → Re-agendamiento
