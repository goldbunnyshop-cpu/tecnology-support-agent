4. PRÓXIMOS PASOS PARA EL USUARIO (Para hacer el Deploy)
═══════════════════════════════════════════════════════════════════════════════

PASO 1: Subir a GitHub
───────────────────────
  $ cd ~/tu-proyecto
  $ git init
  $ git add .
  $ git commit -m "feat: agente WhatsApp con AgentKit - listo para Railway"
  $ git remote add origin https://github.com/TU-USUARIO/whatsapp-agentkit.git
  $ git push -u origin main

PASO 2: Conectar Railway
────────────────────────
  1. Ve a https://railway.app
  2. Nueva proyecto → Deploy from GitHub
  3. Selecciona tu repo "whatsapp-agentkit"
  4. Railway construye automáticamente (usa Dockerfile)

PASO 3: Variables de entorno en Railway
──────────────────────────────────────
  En Railway → tu proyecto → Variables, agregar:
  
  ANTHROPIC_API_KEY = sk-ant-...
  WHATSAPP_PROVIDER = whapi (o meta / twilio)
  WHAPI_TOKEN = ... (si usas Whapi)
  PORT = 8000
  ENVIRONMENT = production
  DATABASE_URL = [Railway genera automáticamente si agregas PostgreSQL]

PASO 4: Configurar webhook en tu proveedor
────────────────────────────────────────
  - Railway te da una URL: https://tu-app.up.railway.app
  
  Si WHAPI:
    → Whapi.cloud → Settings → Webhooks
    → URL: https://tu-app.up.railway.app/webhook
    → Método: POST
  
  Si META:
    → developers.facebook.com → WhatsApp → Configuration
    → Callback URL: https://tu-app.up.railway.app/webhook
    → Verify Token: [el mismo de META_VERIFY_TOKEN]
  
  Si TWILIO:
    → Twilio Console → WhatsApp Sandbox
    → "When a message comes in": https://tu-app.up.railway.app/webhook
